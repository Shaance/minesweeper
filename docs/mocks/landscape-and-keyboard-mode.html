AFTER Keyboard: switch REVEAL / FLAG mode with M

Today keyboard play uses Enter/Space to reveal and F to flag, but there is no key that flips the pointer mode itself. Proposed: M toggles REVEAL ↔ FLAG (same state as the segmented buttons, so the active segment visibly follows the keyboard), and the hints line gains the binding.

What changes (checklist)

  • main: max-width: 480px column → at min-width: 720px a grid of auto 300px (board | rail); below 720px nothing changes.
  • Placement: title + HI-SCORE, HUD (LEDs + face), level row, controls and hints move into the right rail, stacked in the same top-to-bottom order; the board takes the left and sizes from available height (cell = min(56px, (viewport height − chrome) / n)).
  • Board: cell cap raised from 44px to 56px only in landscape; bevels, glow ring and scanlines unchanged.
  • Keyboard: new M binding toggling the shared REVEAL/FLAG mode state (segmented control reflects it); hints line and #keyboard-help text updated.
  • Not changing: palette, sprites, motion, phone layout, game logic.
